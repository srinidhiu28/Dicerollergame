# 🎲 Dice Roller

## 📌 About the Project
Dice Roller is a simple Python application that
simulates rolling a dice and generates a random result.

## ✨ Features
- Random dice results
- Simple user interaction
- Easy-to-understand Python logic

## 🛠️ Technologies Used
- Python 3
- Random Module

## ▶️ How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run:

   python dice_roller.py

- Random Module

- Conditional Statements
- User Input
